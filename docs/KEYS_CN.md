# grid-table 按键

表格 buffer 里的全部按键。这份表照 `grid-table-etaf.el` 里的
`grid-table-etaf--keys` 整理。在 macOS 上，Command 键的快捷键（`s-c`、`s-v`、`s-z` …）也能用。

## 移动和选择

| 按键 | 作用 |
|---|---|
| 方向键，`C-n` `C-p` `C-f` `C-b` | 移动一格 |
| `TAB` / `S-TAB` | 下一格 / 上一格 |
| `C-a` / `C-e` | 第一列 / 最后一列 |
| `M-<` / `M->` | 第一格 / 最后一格 |
| `<next>` / `<prior>` | 向下 / 向上翻页 |
| `S-<方向键>` | 扩大选区 |
| `C-x h` | 全选 |
| `C-c g` | 跳到单元格、区域、列、行或名称（`D120`、`A1:B3`、`B:B`、`Sheet2!A1`） |

光标和选区可以越过最后一行和最后一列；在那里写入内容，表格会自动扩大。

## 编辑

| 按键 | 作用 |
|---|---|
| 任意字符 | 替换单元格内容并开始编辑（把 `grid-table-etaf-type-to-edit` 设为 nil 可关闭） |
| `F2`、`RET` | 编辑单元格原有的文字 |
| `RET`（编辑中） | 存入并下移 |
| `TAB`（编辑中） | 存入并右移 |
| `C-c C-c`（编辑中） | 存入，光标不动 |
| `M-RET`（编辑中） | 在单元格内换行 |
| `C-c C-k`（编辑中） | 取消 |
| `DEL`、`<deletechar>` | 清空选中的单元格 |
| `M-w` / `C-w` / `C-y` | 复制 / 剪切 / 粘贴，连同格式 |
| `C-c y v` | 只粘贴显示的值 |
| `C-c y f` | 只粘贴格式 |
| `C-c y t` | 行列互换后粘贴 |
| `C-d` / `C-r` | 向下 / 向右填充选区 |
| `C-c C-s` | 延续序列（1、2 → 3、4；日期；`Week 1` → `Week 2`） |
| `C-s`（`C-u C-s` 向前） | 查找 |
| `M-%` | 在选区或整个工作表里替换 |
| `C-/`、`C-_`、`C-x u` | 撤销 |
| `C-?`、`C-M-_` | 重做 |
| `C-c t` | 编辑标题 |

## 行和列

| 按键 | 作用 |
|---|---|
| `C-c r i` / `C-c r a` / `C-c r d` | 在上方插入行 / 在下方添加行 / 删除行 |
| `C-c c a` / `C-c c d` | 添加列 / 删除列 |
| `C-c r h` / `C-c r s` | 隐藏行 / 显示选区里隐藏的行 |
| `C-c c h` / `C-c c s` | 隐藏列 / 显示选区里隐藏的列 |
| `C-c s`（加 `C-u` 可按多列） | 排序 |
| `C-c m` / `C-c u` | 合并选区 / 取消合并 |

## 筛选

| 按键 | 作用 |
|---|---|
| `C-c / f` | 按条件筛选光标所在的列 |
| `C-c / v` | 只留下含光标单元格的值的行 |
| `C-c / c` / `C-c / a` | 清除这一列的筛选 / 清除全部筛选 |
| `C-c / d` | 删除重复的行 |

## 格式

| 按键 | 作用 |
|---|---|
| `C-c f b` / `C-c f i` | 粗体 / 斜体 |
| `C-c f c` / `C-c f g` | 文字颜色 / 填充颜色 |
| `C-c f l` / `C-c f e` / `C-c f r` | 左对齐 / 居中 / 右对齐 |
| `C-c f ,` | 带千位分隔符的数字 |
| `C-c f p` / `C-c f $` / `C-c f d` | 百分比 / 货币 / 日期 |
| `C-c f t` / `C-c f G` | 文本 / 常规 |
| `C-c f +` / `C-c f -` | 增加 / 减少小数位 |
| `C-c f n` / `C-c f N` | 添加 / 清除条件格式 |
| `C-c f v` / `C-c f V` | 只允许列表里的值 / 清除这条规则 |
| `C-c f x` | 清除格式 |

## 名称、批注、链接和追踪

| 按键 | 作用 |
|---|---|
| `C-c n d` | 给选区命名（加 `C-u`：给公式命名，如 `=LAMBDA(x,x*2)`） |
| `C-c n l` / `C-c n k` | 跳到名称 / 删除名称 |
| `C-c ;` / `C-c :` | 添加或编辑批注 / 删除选区里的批注 |
| `C-c C-l` / `C-c C-o` | 添加或编辑链接 / 打开链接 |
| `C-c a p` / `C-c a d` | 标出公式引用的单元格 / 标出引用这个单元格的公式 |
| `C-c a n` / `C-c a x` | 依次跳到标出的单元格 / 清除标记 |

## 工作表和窗格

| 按键 | 作用 |
|---|---|
| `C-<next>` / `C-<prior>` | 下一个 / 上一个工作表 |
| `C-c w n` / `C-c w r` / `C-c w d` | 新建 / 重命名 / 删除工作表 |
| `C-c w s` | 按名称切换工作表 |
| `C-c w <` / `C-c w >` | 把工作表左移 / 右移 |
| `C-c w f` / `C-c w u` | 冻结光标上方的行和左边的列 / 取消冻结 |
| `C-c w h` | 打开或关闭表头行 |

## 图表

| 按键 | 作用 |
|---|---|
| `C-c i` | 插入浮动图表 |
| `C-c k t` / `C-c k h` | 图表类型 / 标题 |
| `C-c k s` | 行列互换 |
| `C-c k r` | 改画选中的单元格 |
| `C-c k m` / `C-c k z` | 移到光标处 / 调整大小 |
| `C-c k n` / `C-c k x` / `C-c k d` | 选中下一个 / 取消选中 / 删除 |
| `C-c v` | 在单独的 buffer 里打开图表公式 |

## 文件

| 按键 | 作用 |
|---|---|
| `C-x C-s` | 保存 |
| `C-x 4 c` | 在另一个 buffer 和窗口里再显示这张工作表；在任一边编辑，两边都会刷新 |
| `C-c C-w` | 另存为 |
| `C-c C-f` | 打开表格 |
| `C-c C-r` | 全部重算并重绘 |
| `C-c C-q` | 关闭窗口 |

## 鼠标

| 操作 | 效果 |
|---|---|
| 点击单元格 | 跳到那里 |
| Shift 加点击、拖动 | 选一片区域 |
| 点击行号、列标、左上角 | 选中整行、整列、整张表 |
| 拖动列标的右边缘 | 改列宽 |
| 点击工作表标签 | 切换到那个工作表 |
| 点击 / 拖动图表 | 选中 / 移动图表 |
| 拖到窗口边缘 | 滚动表格 |
| 滚轮 | 滚动 |
| 拖动中按 `Esc` | 停止拖动；图表或列宽回到原样 |
