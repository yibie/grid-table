# Lisp 公式

以 `=elisp:` 开头的单元格放的是一个 Emacs Lisp 表达式，而不是电子表格公式。
这个表达式会被读入并求值，它的值就是单元格的值。

```
=elisp:(+ 1 2)
```

前缀紧跟在 `=` 后面，大小写都行：`=ELISP:` 也可以。

做符号运算的话，用 `CALC` 更安全：`=CALC("deriv(x^2, x)")` 把参数交给
Emacs Calc 计算，不需要允许执行 Lisp。见
[README](../README_CN.md#用-emacs-calc-做符号运算)。

## 打开这个功能

Lisp 公式默认关闭。关闭时，这样的单元格显示 `#ERROR!`，读取它的单元格也一样。

开关是 `exc-allow-elisp`，它是缓冲区局部变量，默认为 `nil`。

| 想允许的范围 | 做法 |
|---|---|
| 所有表格 | 在配置文件里写 `(setq-default exc-allow-elisp t)`。表格一打开就会计算 Lisp 公式。 |
| 某个已经打开的表格 | 在它的缓冲区里 `M-: (setq exc-allow-elisp t)`，再按 `C-c C-r` 全部重算。 |

在 `exc-etaf-mode-hook` 里设置这个变量不起作用：显示表格时，视图会把缓冲区
原来的值放回去，钩子设的值就丢了。这个变量标记为危险变量，所以文件的局部变量要设置它时，
Emacs 会先询问。

Org、Markdown 和 reStructuredText 的预览是在表格缓冲区之外计算的，所以除非默认值是
`t`，预览里的 Lisp 公式都显示 `#ERROR!`。

## 风险

Lisp 公式能以你的用户权限执行任何代码：删文件、读邮件、启动程序。允许 Lisp 公式时，
打开含有它们的 `.grid` 文件会立刻执行。只对自己写的或信得过的文件打开它，并且尽量
只在一个缓冲区里打开，而不是用 `setq-default`。

## 表达式能用到什么

表达式用 `eval` 求值，使用词法绑定。你的 Emacs 里的所有函数和变量都可以用。

`(cell "B2")` 读取公式所在工作表的一个单元格：

| 单元格里是 | `cell` 返回 |
|---|---|
| 数字，输入的或算出来的 | 数字（`12`，不是 `"12"`） |
| 文字 | 字符串 |
| 公式 | 它算出来的值 |
| 空 | `nil` |

`cell` 只接受一个写成文本的单元格，比如 `"B2"` 或 `"$B$2"`。它不能读区域，也不能读
其他工作表：`(cell "Data!A1")` 返回 `nil`。

## 值和错误

| 表达式返回 | 单元格显示 |
|---|---|
| 数字 | 这个数字，按常规格式显示（`(sqrt 2)` 显示 `1.4142135623731`） |
| 字符串 | 这个字符串 |
| `t` | `TRUE` |
| `nil` | `FALSE` |
| 其他东西，比如列表 | 不是单元格能显示的值；请改为返回数字或字符串 |

表达式出错时，单元格里放的是文本 `Elisp Error: ` 加上错误信息。这个值是字符串，
不是错误值，所以 `IFERROR` 捕获不到它，对它做算术的公式会显示 `#VALUE!`。

其他公式可以像读普通单元格一样读 Lisp 公式的单元格：如果 `C2` 是
`=elisp:(* 2 21)`，那么 `=C2+1` 是 `43`。

## 什么时候计算

Lisp 公式在每次编辑后都会重新计算，不管改的是哪里，因为 exc 不知道这段代码读了
哪些单元格。`C-c C-r` 也会计算它。代码要快：慢的代码会拖慢每一次存入单元格。

复制、填充或移动 Lisp 公式时，它的文本保持原样；里面的行号和列号不会调整。

## 示例

下面每一个都在 `B2` 为 `12`、`A2` 为 `pen` 的表格里求值过。

| 公式 | 显示 |
|---|---|
| `=elisp:(+ 1 2)` | `3` |
| `=elisp:(upcase "hi")` | `HI` |
| `=elisp:(string-join (list "a" "b") ", ")` | `a, b` |
| `=elisp:(format-time-string "%Y-%m-%d")` | 今天的日期，比如 `2026-10-20` |
| `=elisp:(> 3 2)` | `TRUE` |
| `=elisp:(* 2 (cell "B2"))` | `24` |
| `=elisp:(length (cell "A2"))` | `3` |
| `=elisp:(/ 1 0)` | `Elisp Error: Arithmetic error` |

这些例子做的事大多有对应的电子表格函数：`=UPPER("hi")`、`=TEXTJOIN(", ",,"a","b")`、
`=TODAY()`、`=B2*2`、`=LEN(A2)`。它们不需要打开任何开关，行移动时引用会跟着变，
而且只在读取的单元格变化时才重算。只有函数做不到的事才用 Lisp 公式。
